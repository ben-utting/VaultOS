## Goal
Find your way around VaultOS, then mark this card done or delete its folder.

## Context / key facts
- **Cards** are `task.md` files. The `status:` line in a card's frontmatter decides its column; dragging the card rewrites that line.
- **Files** shows the vault folder as it is on disk. Every card has its own folder for notes, data and screenshots.
- **Agents**: Start agent opens a terminal in the card's folder and asks your coding agent for a brief. `AGENTS.md` at the top of the vault tells any agent how the boards work.
- **Knowledge Base**: when a job is finished, its agent writes an `article.md` next to the `task.md`. The Knowledge Base collects them.
